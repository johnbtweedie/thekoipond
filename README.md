# The Koi Pond

Public pages for The Koi Pond's clip publishing tool, served by GitHub Pages:

- `index.html`: home page
- `privacy.html`: privacy policy
- `terms.html`: terms of service
- `tiktok/callback/`: the TikTok sign-in redirect. It shows the one-time code so it can be pasted into `link-tiktok`; it sends nothing anywhere.

URLs: https://johnbtweedie.github.io/thekoipond/ (privacy: `/privacy.html`, terms: `/terms.html`, TikTok redirect URI: `/tiktok/callback/`).
